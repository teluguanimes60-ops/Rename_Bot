# AniToon_1Bot 🎬

AniToon_1Bot is a Telegram media utility bot built with **Python, Pyrogram, MongoDB/Motor and FFmpeg**.

## Features

- ✏️ File renaming
- 🎬 Video processing
- 🔄 Media conversion
- 🖼 Thumbnail support
- 📊 Download/upload progress
- ⏳ Queue management
- ⏸ Pause/resume/cancel workflows
- 📦 2 GiB per-file application limit
- 🔐 Force Subscribe
- 🤖 Clone bot support
- 👑 Owner-only administration
- 💎 Plan and usage management
- 🎥 Telegram video delivery

## Owner Access

AniToon uses a single owner.
